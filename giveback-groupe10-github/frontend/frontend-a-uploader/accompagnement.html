Déclarer un accompagnement

Réservé aux membres de l'équipe et mentors — pour tracer les vrais accompagnements réalisés.

💡 Utilisez un code anonyme pour la personne aidée (jamais son vrai nom). Ajoutez une preuve si possible (capture d'écran de l'échange, confirmation) — elle reste privée, seule la coordination y a accès.
